# Security Policy

The following table details which versions of this project are currently supported with security updates:

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |
| < 1.0.0 | :x:                |

## Reporting a Vulnerability

We take the security of this project seriously. If you believe you have found a security vulnerability, please follow these steps:

1. **Do NOT open a public GitHub issue.** Public issues disclose vulnerabilities before a fix can be prepared.
2. Report the vulnerability privately using **GitHub Security Advisories**:
   * Go to the **Security** tab of this repository.
   * Click on **Report a vulnerability**.
3. Alternatively, email the maintainer directly at: `your-email@example.com`

### Please Include

* A description of the vulnerability and its potential impact.
* Step-by-step instructions or a Minimal Working Example (MWE) to reproduce the issue.
* Any suggested fixes or mitigations if available.

## Response & Disclosure Process

* **Acknowledgement:** You will receive an initial response within 48 hours acknowledging receipt of your report.
* **Assessment:** We will investigate the issue and determine its impact and severity.
* **Fix & Advisory:** If confirmed, a fix will be developed and released in a patch update alongside a public security advisory crediting your contribution (unless you prefer to remain anonymous).
